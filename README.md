# Sales and Profit Dashboard (Excel)

## Overview

This project is an interactive **Sales and Profit Dashboard** created using **Microsoft Excel**. It provides a clear and concise view of sales performance, profit trends, and key business metrics through dynamic charts, PivotTables, and slicers. The dashboard helps users analyze business performance and make data-driven decisions.

## Features

* Interactive dashboard with slicers for easy filtering
* Sales and profit analysis
* Dynamic PivotTables and PivotCharts
* KPI summary for quick insights
* Trend analysis by category, region, or time period
* Clean and user-friendly dashboard layout

## Tools & Skills Used

* Microsoft Excel
* PivotTables
* PivotCharts
* Slicers
* Conditional Formatting
* Data Cleaning
* Excel Formulas (SUM, IF, COUNTIF, INDEX-MATCH/XLOOKUP, etc.)

## Key Insights

* Track overall sales and profit performance.
* Compare performance across different categories and regions.
* Identify top-performing products and sales trends.
* Monitor key business metrics through an interactive dashboard.

## Purpose

This project was developed to strengthen my Excel and data analysis skills by transforming raw sales data into meaningful visual insights. It demonstrates my ability to clean data, analyze business performance, and build interactive dashboards for reporting and decision-making.
